## Nuts chat link

```
da.gd/avn
```

That opens the install page. Do not share `da.gd/nva` — that one is stuck on the GitHub repo.

## What it is

Skims a percentage of play-balance profits into the vault on [nuts.gg](https://nuts.gg).

- **Computer:** Tampermonkey → install from the page
- **Phone:** Firefox + Violentmonkey (not the Play Store Tampermonkey app), or the bookmark on the page
- **Tip box:** checked by default (1% of vault withdrawals to `@jmenichole`). Uncheck it in the panel to opt out.

Script source is the TiltCheck-ME nuts AutoVault, copied here so the page can serve it.
