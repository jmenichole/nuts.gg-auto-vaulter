Play Store Tampermonkey is a fake sandbox. Use Firefox + Violentmonkey, or the bookmark on nuts.gg.

  1. Install Firefox (Android) or use Safari bookmarks (iPhone).
  2. Android: add Violentmonkey, then tap Install script below.
  3. iPhone / no add-ons: open nuts.gg, then tap the bookmark you add from the button below.
  4. Log in, hit Start on the purple AutoVault panel.
